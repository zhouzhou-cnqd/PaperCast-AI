# PaperCast AI 比赛版验收报告

> 初次验收：2026-11-22 · 最后更新：2026-11-24

## 结论

比赛版已形成可独立访问的线上产品：10 篇论文播客可以播放和按章节跳转，用户用文字选择「快速」或「深度」问答，回答后可恢复播放。公网不依赖本地 Python 服务；深度模式由 Qoder Deno Function 检索完整论文解析文本并调用 DeepSeek。

本地原版继续保留语音输入、faster-whisper、Qdrant Hybrid 和 DeepSeek 的完整研究链路，用于生成、评测和技术展示。两条链路的指标在本文中分开报告。

## 公网部署

- 地址：https://papercast-ai-koyte7vo1mh.qoder.zone
- 最新确认发布 action：`10ec75c0-f580-4d19-ba75-80f23bfc1146`
- 访问策略：public，无需登录。
- 内容：10 篇论文、183 段双角色中文播客，单篇 16–20 段。
- 输入：生产环境仅显示文字输入；不请求麦克风权限。
- 回答：快速模式为节目文本检索；深度模式为完整解析文本检索 + DeepSeek。
- 额度：每位访客最多 3 次深度问答，由服务端签名状态和远端计数共同约束。

## 完整文本与深度问答

- `prepare:static` 从 10 份 `paper.json` 生成 12,758 个 Docling 文本块。
- 服务端全文模块约 2.42 MB，只进入 Qoder Function 部署包，不进入浏览器静态资源或公开 Git 仓库。
- 深度检索在当前论文范围内选择最多 10 条候选证据，再交给 DeepSeek 生成 250–500 字的中文回答。
- 回答后过滤不存在的 evidence ID；无充分证据时要求明确说“论文未提供”或“我不确定”。
- 公网回归样例返回 467 个字符，采用 9 条证据；报告为 `bundled_fulltext` / `deepseek_grounded_answer`。
- 旧 10 问检索集在服务端完整文本检索上重跑为 10/10 命中。

## 自动测试与构建

- Deno 边缘函数：9 项测试通过，覆盖健康检查、快速回答、深度回答、额度耗尽、越界拒答、非法输入与路由收口。
- 前端：TypeScript 检查和 Vite 生产构建通过。
- 深色主题断言：`body` 背景 `rgb(14, 12, 20)`，文字 `rgb(236, 233, 244)`；构建样式不含 `#e7e0ea` 或 `color-scheme: light`。
- 静态元数据：10 篇论文均存在对应播客 JSON 与音频。
- 公网：主页、论文列表、边缘探针与快速问答均能成功响应。

## 本地原版基线

- Python：16 项测试通过。
- 真实语音问答：Docling 10/10、DBDA 10/10，总计 20/20，无崩溃、无论文串线。
- 平均端到端耗时：3.68 秒；P95：4.0 秒；20/20 小于 10 秒。
- Qdrant Hybrid 10 问评测：10/10 Top-3 命中。
- 内容覆盖：摘要、方法、实验结果、局限/未来工作和英文问题均实测。

上述速度和语音指标属于本地 faster-whisper + Qdrant + DeepSeek 链路，不能直接等同于公网 DeepSeek 延迟。

## 安全与内容边界

- `.env`、API Key、源 PDF 和本地模型权重不提交 Git。
- API Key 仅由函数端环境变量读取。
- `/data/*` 和公开问答响应不包含 `quote` 或 `passage_text` 原文字段。
- 服务端全文只作为检索上下文，不向前端直接暴露。
- 生产函数不包含平台探测期的 `echo`、`sleep` 或 `egress` 调试路由。

## 已知限制

- 不支持网页上传 PDF；当前采用 10 篇预生成论文。
- 深度模式依赖 DeepSeek 服务并限制每位访客 3 次。
- 互动回答为文字，不生成额外 TTS。
- 仍需提交人用参赛账号发布作品帖，并在真机上做一次最终文字交互检查。
